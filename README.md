# C500 MoE 算子学习

这是从零开始的教学目录。用自然语言描述一个小功能，由 AI 协助实现、讲解和验证，再逐步理解 grouped GEMM 和 MoE 优化。

## 位置与分支

- C500 工作目录：`/root/MOE/C500_int8_02All`
- GitHub：`William7743/DeepGEMM`
- 教学分支：`DeepGemm-MUXI-Learn`
- 正式适配分支：`DeepGemm-MUXI`

教学分支以独立历史从空目录起步，不预先复制正式适配实现，也不包含整个上游 DeepGEMM 源码。阅读上游结构时使用已有仓库作为参考。当前仅建立学习目录，尚未实现任何 GPU 功能。

## 学习顺序

1. 认识 DeepGEMM 的功能、仓库结构及它在 MoE 中的位置。
2. 编写最简单的 MACA C FP32 矩阵乘法，理解 M/N/K 和线程映射。
3. 扩展到两个专家，再处理各专家不同的 token 数。
4. 引入 INT8 输入、INT32 累加和缩放写回，检查算子精度。
5. 学习分块与数据复用，再逐步接触 MMA 和流水线。
6. 使用计时和性能分析工具，每次验证一个优化假设。

这些是学习方向，不意味着一次生成全部代码。具体练习随学习进度确定。

## 每个小功能的完成方式

1. 先说明输入、输出、计算过程和期望结果。
2. 编写最小可理解的实现，并解释新增的关键代码。
3. 在 C500 上运行，记录正确性结果；涉及优化时记录前后计时口径和数据。
4. 用自己的话解释关键部分，再提交该功能并推送到教学分支。

每个练习使用独立的编号目录，例如 `01_naive_gemm/`。目录中包含源码、构建/运行命令和简短笔记；运行产物不提交。功能尚未验证时明确标注，不写成“通过”。

每个完成的小功能对应一个清晰的 Git 提交，便于逐步查看变化和回顾，不把多个学习阶段压在一个提交里。
