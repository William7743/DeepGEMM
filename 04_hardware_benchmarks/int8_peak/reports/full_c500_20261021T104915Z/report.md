# 完整 C500：INT8 MMA 算力实测（2026-10-21）

## 结论

本次设备确认是 sGPU Disabled 的完整 MetaX C500，物理显存 65536 MiB，测试前 GPU 利用率 0%、没有可见 GPU 进程。
可重复的 INT8 MMA 算力参考约为 **477 TOPS**，按每次乘法和加法各计一次 OPS。

三段连续计算验证的 Event 平均吞吐为 **477.047168 TOPS**；
CPU 墙钟平均吞吐为 **477.039410 TOPS**。
两种计时差约 0.001626%；三段耗时极差/中位数为 0.009446%。

此值是当前设备、当前非零 INT8 输入与测试代码下的实测算力参考；没有据此宣称官方理论峰值或实际 grouped GEMM/MoE 的端到端性能。

## 方法与验证范围

- 原 MMA kernel 未修改；使用 C500 的 __builtin_mxc_mma_16x16x16i8，INT8 输入、INT32 累加。
- 扫描 12 档 blocks × 4 档线程数 × 5 档累加器，共 240 个配置，统一 iterations=4096。
- blocks：1、8、16、32、64、104、208、416、832、1664、3328、6656；线程数：64、128、256、512；累加器：1、2、4、8、16。
- 另测 blocks=13312/26624 与 accumulators=8/16 的 4 个扩展配置；上述 244 个初步配置均通过正确性检查。
- 对 7 个候选配置执行 3 轮验证，每轮每配置 10 个样本，共 210 个样本；每个样本都检查最终输出的所有 wave/累加器。
- 每组验证前先做数值预检并连续预热至少 2 秒。轮内顺序以固定种子打散；各样本执行 1..8 个 kernel，计时窗口约 120 ms。
- 额外使用 3 个样本，每样本连续执行 256 个 kernel，单个样本约 30.68 秒，总计约 92.046 秒 GPU 计算。
- 输入分配/拷贝、输出初始化、回读、CPU 校验和打印均在 Event 与墙钟区间外。kernel 内初始加载和最终写回计入。
- 墙钟还包含 Event/kernel 提交及最后等待的开销。它不包含整个程序的数据准备和校验开销。
- 每个 kernel 的 INT32 累加器都从零开始，batch 之间不在同一 INT32 值上继续累加；batch 内中间输出覆盖同一个 C，不逐个保留。

运算量与主指标：

```text
OPS/kernel = blocks × (threads/64) × accumulators × iterations × 8192
OPS/batch  = OPS/kernel × kernels_per_sample
TOPS       = OPS/batch ÷ (同配置样本的算术平均耗时 ms × 1e9)
```

不重复乘线程数、AP 数、乘加的 ×2，也不使用最快样本代替平均耗时。

## 环境与监测

- MACA 3.7.1.5，驱动 3.8.30，编译器 mxcc 1.0.0 (d9102a1572)。
- 构建：-O3 -std=c++17 -x maca -offload-arch=xcore1000；脚本与此前相同。
- runtime arch=xcore1000，wave=64，运行时可见显存 65120 MiB。
- 运行时报告 AP=104、核心频率 1600 MHz；这些字段不用于计算实测吞吐。
- DPM 核心最高档位 1125 MHz，HBM 控制器频率 1800 MHz。实际时钟采样与运行时上报值分开记录。
- 连续负载阶段监测 98 个管理接口快照，最高温度 64.75 C，最高板卡功耗 286.676 W。
- 这些快照中未见 Over Power 或温度限频原因激活；一秒级采样不能排除更短的瞬时事件。
- Idle 未激活的 97 个快照中，核心时钟范围 1125.0..1125.0 MHz。
- 管理接口约每秒查询一次；没有在计时中使用 profiler、上传源码或编译。使用本实例的独占文件锁；测试前后状态单独保存。

## 编译器与正确性证据

- 1/2/4/8/16 累加器的优化后 LLVM IR 热循环分别保留 1/2/4/8/16 个 MMA intrinsic 和同数量的独立向量累加链。
- 热循环中没有 load/store；运行时资源属性显示五种模板 local_bytes 均为 0，kernel 最大线程数均为 512。
- 核对层级为优化后 LLVM IR 与运行时资源属性，没有声称完成原生 ISA 反汇编。
- 数值参考使用 CPU INT64；所有采样的最终输出逐元素精确匹配，允许最大循环次数 8191 的保守 INT32 安全界限保持不变。
- 7 项协议预检通过，包括 2 个有效配置与 5 个预期拒绝场景；bad_samples 等日志中的 Error 是预期结果。
